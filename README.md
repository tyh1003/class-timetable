## ✨ 關於 Class Timetable

**Class Timetable** 是一款以「自由、自訂、快速查看」為核心設計的 Android 課表工具。

不同學校、不同科系，甚至不同學期的上課時間都可能完全不同，因此這個 App 不把使用者限制在固定的課表格式裡。

你可以自由設定自己的 **學期／年級、上課節次、時間、課程分類、顏色與字體大小**，並直接點擊課表上的格子安排課程。

更重要的是：

> 🏠 **課表不一定要打開 App 才能看。**

Class Timetable 提供 Android **桌面課表小工具（Widget）**，可以直接把整張課表放在手機桌面上。

就像把 App 裡的課表直接搬到桌布上一樣，解鎖手機就能確認今天與這週的課程。

# 🏠 把整張課表放到桌面

<p align="center">
  <img src="screenshots/widget.png" width="420" alt="Android 桌面課表 Widget">
</p>

Class Timetable 特別設計了 **Android 桌面課表 Widget**。

它不是只有「下一堂課」的小卡片，而是直接將完整課表呈現在手機桌面。

### Widget 支援

- 📅 直接顯示完整學期課表
- 🎓 新增 Widget 時選擇要顯示的學期
- 🧩 預設適合桌面的 **3 × 3** 尺寸
- ↔️ 支援 Android 桌面自由縮放
- 🔎 Widget 放大時會同步重新調整課表與文字大小
- 🎨 保留 App 中的課程分類顏色
- 🏫 顯示課程名稱與上課地點
- 🔗 連續課程自動合併成一個區塊
- ✅ 已修畢課程同步顯示完成狀態
- 👆 點擊 Widget 即可快速回到 App

你可以依自己的桌面配置把課表拉大，讓它成為手機桌面的一部分。

# 🎨 課程類別，由你定義

<p align="center">
  <img src="screenshots/category-colors.png" width="320" alt="自訂課程類別與顏色">
</p>

不是每堂課都一樣。

Class Timetable 可以透過不同的 **課程類別與顏色**，讓一整週的安排一眼就能辨識。

預設提供：

| 類別 | 用途 |
| --- | --- |
| 🔴 必修 | 系所必修、核心課程 |
| 🔵 選修 | 自由選修課程 |
| 🟢 論文 | 論文、研究相關時段 |

除了預設分類之外，也可以自行建立新的類別，例如：

`通識`、`實驗`、`實習`、`專題`、`體育`、`研究室`……

每個分類都可以設定自己的顏色。

**你的課表，不需要跟別人的長得一樣。**

# ⏰ 上課時間不固定？自己設定

<p align="center">
  <img src="screenshots/time-slots.png" width="320" alt="自訂課表時程">
</p>

不同學校的節次制度差異很大，因此 Class Timetable 的節次並不是寫死的。

你可以：

- ➕ 新增節次
- ✏️ 修改節次名稱
- 🕐 自訂開始時間
- 🕐 自訂結束時間
- 🗑️ 刪除不需要的節次
- 🔄 依自己的學校建立完整時程

預設時程包含：

| 節次 | 時間 | 節次 | 時間 |
| :---: | :---: | :---: | :---: |
| y | 06:00 – 06:50 | z | 07:00 – 07:50 |
| 1 | 08:00 – 08:50 | 2 | 09:00 – 09:50 |
| 3 | 10:10 – 11:00 | 4 | 11:10 – 12:00 |
| n | 12:20 – 13:10 | 5 | 13:20 – 14:10 |
| 6 | 14:20 – 15:10 | 7 | 15:30 – 16:20 |
| 8 | 16:30 – 17:20 | 9 | 17:30 – 18:20 |
| a | 18:30 – 19:20 | b | 19:30 – 20:20 |
| c | 20:30 – 21:20 | d | 21:30 – 22:20 |

如果你的學校不是這套時間？

**直接改成自己的就好。**

## 🖱️ 直接在課表上選時間

Class Timetable 支援直接從課表畫面選取課程時間。

例如一門「論文」安排在：

```text
星期一：第 5、6 節
星期五：第 9 節
```

你可以直接點：

```text
✓ 星期一 5
✓ 星期一 6
✓ 星期五 9
```

再一次填寫課程資料即可。

因此除了常見的連堂課之外，也支援：

- 同一天多個時段
- 非連續節次
- 跨星期多個時段
- 多節連堂

不需要為同一門課建立好幾筆重複資料。

---

# 🧩 連堂課，自動整理

如果同一堂課是：

```text
星期一
第 5 節 ┐
第 6 節 ├─ 論文
第 7 節 ┘
```

課表不會顯示三張重複的卡片。

Class Timetable 會自動把連續課程合併成一個完整區塊，課程名稱與教室也只需要顯示一次。

讓整張課表更接近真正的紙本／學校課表，而不是一格一格重複資訊。

---

# ✅ 修完一堂課，也值得打勾

學期結束後，可以將課程標記為 **已修畢 ✓**。

完成的課程會透過：

- ✓ 完成標記
- 半透明課程色塊
- 完成狀態視覺效果
- 課程名稱劃記

與仍在進行中的課程做出區別。

桌面 Widget 也會同步顯示完成狀態。

看著一整個學期的課程慢慢被打勾，也算是一種小小的成就感。

---

# 🗓️ 一眼看到整週

Class Timetable 的主要目標不是塞進更多功能，而是：

> **打開課表，就看到課表。**

預設以週一至週五為主要畫面，也可以加入週六、週日。

課表支援依照螢幕空間調整尺寸，盡可能讓完整時程集中在同一個畫面中；需要更大的內容時，也可以切換成放大瀏覽方式。

---

# 🌿 Natural Tones

整體 UI 採用偏柔和、自然的 **Natural Tones** 設計。

相較於高飽和度的課表配色，希望在每天都會查看的情境下，維持：

- 清楚的資訊層級
- 柔和的課程色塊
- 簡潔的課表格線
- 圓角卡片
- 容易閱讀的文字對比
- Light / Dark Mode 的一致體驗

課程顏色除了辨識用途之外，也是整體課表視覺的一部分。

# 💡 為什麼做這個 App？

很多課表 App 可以「記錄課程」。

但真正使用時，每個人的需求其實差很多：

> 我的學校節次跟別人不一樣怎麼辦？  
> 我想把「論文」跟「必修」用不同顏色區分。  
> 我的課不是連續時段。  
> 我想保存大一到大四不同的課表。  
> 字太小，我想自己調。  
> 我不想每次都打開 App 才知道等等要上什麼課。  

因此 Class Timetable 希望做的不是一套固定格式的課表。

而是一張 **可以配合你的學校、你的學期，以及你的使用習慣改變的課表。**
